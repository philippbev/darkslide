# Security

Please report a security vulnerability privately, not in a public issue. Either:

- use **Report a vulnerability** on this repository's **Security** tab, or
- email fujicookbook@grovehouse.xyz.

Include what you found, how to reproduce it, and which app version (**Settings ▸ About**) and iOS
version you used. We'll acknowledge the report, keep you updated while we work on a fix, and credit
you when it ships unless you'd rather we didn't.

In scope: the app, the Share Extension, and how they handle API keys, iCloud data and the files
they import. Out of scope: Fujifilm camera firmware, and the AI providers' own services.
