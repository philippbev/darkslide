# Code of Conduct

Fuji Cookbook follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies in the repository, its issues and pull requests, and anywhere else you represent the
project.

Report unacceptable behavior to fujicookbook@grovehouse.xyz. Reports are handled privately, and
the maintainers will act on them as the Covenant's enforcement guidelines describe.
